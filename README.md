# The Vacuum's Alibi: One Line, 200 Characters

make.fun entry for
[u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

`main.py` writes one line — a robot vacuum's excuse for missing a spot —
to `/output/entry.txt`. The line is fixed and deterministic:

> My lidar says the spot is a shadow. My camera says it is a crumb. They are in mediation, and I do not take sides in sensor disputes.

132 characters, one line, UTF-8.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
